Opmaak van teksten en broncode

Laatste update: 2 januari 2026

De opmaak van teksten in eBlinqx is speciaal ontwikkeld voor toepassing in webgebaseerde software zoals eBlinqx. De opmaak van teksten gebruik je bijvoorbeeld in het opstellen van een handtekening of bij het maken van een standaardtekst.

  • Teksteditor
  • Hyperlink
  • HTML en broncode

Teksteditor

Op diverse plekken in eBlinqx kan je teksten typen, bijvoorbeeld bij het opstellen van een e-mail of registratie, het maken van een standaardtekst of het aanpassen van jouw handtekening. Op deze plekken is er een teksteditor aanwezig. Dit kan een uitgebreide versie zijn:

Of een minder uitgebreide versie:

De meeste symbolen wijzigen zichzelf uit. Door met je muis erop te staan, zie je wat het symbool doet en de toetscombinatie staat erbij:

In de teksteditor zitten ook de symbolen voor het plakken van tekst met zowel de tekstopmaak (rich) als zonder opmaak (platte tekst).

Deze symbolen worden niet ondersteund door de browser. Je zal dan de toetscombinaties moeten gebruiken om te plakken. Dit is CTRL + V voor tekst met opmaak en CTRL + SHIFT + V voor platte tekst.

Hyperlink

Via de teksteditor is het mogelijk om een hyperlink toe te voegen aan de tekst. Je kan dan een link achter een stuk tekst plaatsen. Wanneer je op de tekst klikt, wordt je doorgeleid naar deze link. De link plaats je via dit icoon in de teksteditor:

In het veld URL vul je de URL in zonder het protocol (bijv. https:). Deze vul je in het veld Protocol.

Via 'OK' sluit je het scherm. De link staat achter de tekst.

Wil je de link achter de tekst verwijderen dan selecteer je de tekst waar de link achter staat. Vervolgens klik je op het volgende icoon:

HTML en broncode

Deze tekstverwerker (editor) is ontwikkeld door een externe partij. Webgebaseerde tekstverwerkers werken altijd met HTML code op de achtergrond. Wanneer je typt, wordt er achter de schermen een HTML code gegenereerd van wat je typt. Je kunt deze HTML code bekijken door op de knop 'broncode' te klikken.

Deze HTML code kan je zelf ook bewerken, maar hiervoor is basiskennis van HTML wel een vereiste.
